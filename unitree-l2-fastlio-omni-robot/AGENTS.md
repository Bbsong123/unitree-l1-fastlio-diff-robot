# 代码协作规则

用中文交流，未经用户要求不提交或推送代码。

本目录由父目录统一 Git 仓库管理，版本管理遵循父目录 `AGENTS.md`；不在本目录重新初始化 Git 或建立独立工作树。

## 实验代码编写准则

- 本项目部署在额外的 NUC 上，属于实验代码；以简单、直观、可读和最基本数据流能跑通为先。
- C++ 统一使用 C++14。新增或实质修改的自写代码补充详细中文注释，解释数据来源、去向、坐标系、单位及关键语句的用途。
- 当前按用户明确要求保留基础速度限幅、可配置话题及无有效指令时发零停车；不自行扩展平滑、上层控制算法、增益参数、复杂保护或测试体系。
- 优先直接调用官方驱动，保留必要的节点、话题与启动文件；不为未来需求增加抽象层、通用配置或工程框架。
- 检查以必要的语法、配置和实际运行验证为主，不为简单转发逻辑建立测试目录。无法在当前环境运行的部分如实说明。
- 每次实际修改代码后，最终回复必须详细说明：修改了哪些文件和功能、删除或保留了什么、当前数据流与使用方式、完成的检查及未验证事项。不能只用一句“已完成”收尾。
